# Java Learning Repository

My notes and practice code while learning Java, organised chapter by chapter.
Every folder is a small IntelliJ-style project with its own `src/` directory.

## Structure

| Folder | Topics |
|---|---|
| `chapter-1` | Java basics, data types and variables, operators, if-else, loops, break/continue, functions, return, arguments vs parameters, 1D and 2D arrays |
| `Chapter-2` | Classes and objects, switch, ternary operator, `toString`, String class and formatting, `StringBuilder`, Math and Random, recursion |
| `OOPsCore` | Encapsulation, inheritance, polymorphism, abstraction |
| `Chapter-3` | Collections and generics, varargs, exception handling, file handling, multithreading and `ExecutorService`, functional programming (lambdas, streams, Optional) |
| `Challenges` | Practice problems (`Question_15` to `Question_57`) |

## How to run

1. Install JDK 21 or newer (some files use newer syntax such as instance `main`).
2. Open a folder in IntelliJ IDEA, or compile from the terminal:

```bash
cd Chapter-2/Recursion/src
javac *.java
java Main
```
